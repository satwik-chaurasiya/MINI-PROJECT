Why consumers consistently overpay for high-ticket electronics.

📉

Algorithmic Volatility

E-commerce giants change prices thousands of times each day based on algorithmic demand repricing, causing price spikes without warning.

MACHINE LEARNING

Predictive Modeling: Facebook Prophet

Why an additive decomposable time-series model outperforms standard regression.

Mathematical Formulation

y(t) = g(t) + s(t) + h(t) + εₜ
  • g(t) [Trend]: Non-linear logistic growth curve capturing gradual hardware depreciation over time.
  • s(t) [Seasonality]: Periodic weekly shopping spikes (weekends) and annual discount cycles.
  • h(t) [Holidays/Events]: Models sudden pricing dips during Diwali, Republic Day, and Prime Day.
  • εₜ [Error]: Normally distributed residual noise.

Uncertainty Bounds & Decision Rules

Prophet outputs Bayesian posterior intervals generating upper ($yhat_{upper}$) and lower ($yhat_{lower}$) bounds with an 80% confidence level.

Verdict Decision Rule:
If Expected Savings > 3.0% ➔ WAIT (⏳)
Else ➔ BUY NOW (🟢)
DATA ENGINEERING

Data Harvesting & Synthesis Pipeline

Overcoming cold-start data scarcity with realistic retail modeling.

🕷️

1. Live Web Harvesting

BeautifulSoup4 engine with dynamic User-Agent rotation, session retry backoffs, and CSS selector matching for Amazon.in and Flipkart listings.

🔬

2. 365-Day Price Synthesis

For unseeded items, synthesizes realistic historical trends combining 15% annual depreciation, sine-wave cyclicality, Gaussian noise, and periodic discount shocks.

⚓

3. Zero-Leakage Alignment

Backward array generation forces the exact final data point to perfectly match today's live scraped retail price, guaranteeing smooth model continuity.

ENGINEERING HIGHLIGHTS

System Resiliency & Reliability

Built to withstand real-world scraping constraints and production deployment.

🛡️

3-Tier Fallback Hierarchy

  • Tier 1: Direct live scraping of Amazon.in and Flipkart.
  • Tier 2: Intelligent benchmark matching for flagship devices.
  • Tier 3: Open DummyJSON API fallback for long-tail search queries.
🐳

Production Docker Setup

  • Orchestrated via docker-compose.yml.
  • Isolated FastAPI Python 3.10 backend container.
  • React 19 Node 18 frontend container.
  • Redis 7 alpine container for high-speed caching.
🎨

Full Multi-Theme Engine

  • Seamless CSS custom property toggles for Dark, Light, and Retro modes.
  • Bcrypt salted password hashing with JWT Bearer session tokens.
  • Responsive layouts for desktop, tablet, and mobile browsers.
